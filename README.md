# 🛍️ InfoTec Store

Site institucional/e-commerce de uma loja de informática, desenvolvido com **HTML5 e CSS3**. Apresenta catálogo de produtos (notebooks, armazenamento, periféricos), ofertas e página de contato.

## 🔗 Demo ao vivo

👉 **[marcositz.github.io/siteloja](https://marcositz.github.io/siteloja/)**

## ✨ Funcionalidades

- 🏠 Página inicial com banner e categorias em destaque
- 💻 Catálogo de **notebooks**
- 💾 Seção de **armazenamento** (SSDs, HDs, NVMe)
- ⌨️ **Kits** de teclado e mouse
- 🔥 Ofertas da semana
- 📩 Seção de contato

## 🛠️ Tecnologias

- HTML5
- CSS3

## 📂 Como rodar localmente

```bash
git clone https://github.com/marcositz/siteloja.git
cd siteloja
# abra o index.html no navegador
```
